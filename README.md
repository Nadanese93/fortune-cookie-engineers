# Fortune Cookie Funnies for Engineers

A one-line fortune cookie message for a software engineer, built for the Make.fun bounty "Fortune Cookie Funnies for Engineers".

> "You will explain your bug to a rubber duck. The duck will fix it. You will take the credit."
